
你是一个资深前端工程师。请在当前目录生成一个可运行的前端项目，项目目录为 `front-show`，用于对接一个 Java Spring Boot 后端的“编程小助手”接口。

## 1. 项目目标
构建一个简洁、可用、可演示的“编程小助手”Web 页面，支持：
- 流式问答（逐步显示模型输出）
- 会话隔离（通过 `memoryId` 区分不同会话）
- 基础错误提示与加载状态

页面语言默认中文。

## 2. 技术栈要求（必须）
- Vue 3（`<script setup>`）
- Axios（普通请求）


## 3. 后端接口契约（按此实现）
后端基础地址：`http://localhost:8080`



### 3.1 流式聊天
- Method: `GET`
- URL: `/aihelper/chatStream/{memoryId}/{message}`
- 示例：`/aihelper/chatStream/user-001/重庆的天气怎么样明天`
- 返回：`Flux<String>` 按块输出文本
- 注意：后端当前 `produces` 为 `text/html;charset=UTF-8`，不是标准 SSE，因此前端**不要使用 EventSource**，请使用 `fetch` 读取 `response.body.getReader()`。

### 3.3 编码要求
- `message` 与 `memoryId` 都需要使用 `encodeURIComponent`
- 防止中文、空格、特殊符号导致 URL 解析错误

## 4. 页面与交互需求
生成一个单页应用，页面风格为聊天室，至少包含：

1. 顶部区域
- 标题：`AI 编程小助手`
- 副标题：`支持普通问答与流式输出`

2. 参数区
- 输入框：`memoryId`（默认值：`user-001`）
- 文本域：用户问题

3. 按钮区
- `提问`：调用流式接口

4. 消息区（核心）
- 按时间顺序展示消息
- 区分角色：用户 / 助手
- 助手流式输出时，内容应实时追加，不要闪烁重排
- 自动滚动到底部

5. 状态区
- 展示当前状态：空闲 / 请求中 / 流式输出中 / 出错
- 出错时显示错误文案

## 5. 样式要求（简单但不要太简陋）
- 整体布局：居中卡片式，最大宽度 960px
- 背景：浅灰渐变
- 卡片：白底、圆角、轻阴影
- 字体：优先 `"Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 颜色建议：
  - 主色：`#2563eb`
  - 成功：`#16a34a`
  - 警告：`#d97706`
  - 错误：`#dc2626`
- 消息气泡：
  - 用户：浅蓝背景靠右
  - 助手：浅灰背景靠左


## 6. 错误处理要求
- 网络错误、后端 4xx/5xx、流式中断都要显示明确提示
- 流式被手动停止时，提示“已停止生成”而不是“请求失败”
- 避免未捕获 Promise 异常

## 7. 可运行要求
- 提供 `npm install`、`npm run dev`、`npm run build` 命令
- `README.md` 说明如何配置后端地址（默认 `http://localhost:8080`）
- 不要省略关键代码，确保项目可直接运行
